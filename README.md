# HTMLCreator  

Create, edit, and read HTML Books ( HTMLBook / WebBook ) online or offline with static or animated text, images, video, and audio using htmlcreator ( htmlcreator is a self-contained app delivered as an HTML file that runs directly in your computer’s web browser, with no installation or internet connection required ).
