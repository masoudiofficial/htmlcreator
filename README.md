# HTMLCreator  

Create, edit, and read HTML Books ( Web Books ) online or offline with static or animated text, image, video, and audio using HTML Creator for free.  

HTMLCreator benefits :  
🟢 Add static or animated text, images, video, and audio ( live preview )  
🟢 No internet connection required while creating or editing  
🟢 Read books directly in any modern web browser ( no special ebook reader required )  
🟢 Host your books on your own website ( publish your book as an seo-optimized web page )  
🟢 Free to use
